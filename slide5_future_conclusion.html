Proposed Future Additions
Exploratory Roadmap
Roadmap 01
Drag-and-Drop Editing
An interactive browser canvas to manually nudge nodes, tweak alignment, or adjust coordinates post-generation.
Roadmap 02
Real-Time Collaboration
Multi-user review threads, shared comments, and simultaneous live editing directly on diagram files.
Roadmap 03
Multi-Format Native Export
Direct 1-click export to native PowerPoint (.pptx), vector PDF, and raster PNG without headless CLI tooling.
Roadmap 04
Version History & Diffs
Semantic change tracking and visual diffs to audit additions, removals, and rewiring across Git commits.
Roadmap 05
Enhanced Auto-Validation
Automated heuristics to flag disconnected components, dangling relationships, and overlapping bounding boxes.
Roadmap 06
Expanded Agent Ecosystem
Broader integration across new web IDEs, autonomous documentation bots, and CI/CD diagram generators.

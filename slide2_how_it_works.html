4-Stage Generation Pipeline
1
Describe
The user describes the target architecture, workflow, data model, or sequence using conversational, natural-language prompts.
2
Select & Plan
The AI agent identifies the best-fit diagram type from 45 specifications, loads layout budgets, and calculates coordinates on a strict 4px grid.
3
Generate
The agent writes clean, self-contained semantic HTML embedding responsive inline SVG, 1px hairlines, and accessible ARIA attributes.
4
Render & View
The user opens the resulting .html file immediately in any browser with zero compilation, dependencies, or external scripts.
01
45 Diagram Types
Comprehensive coverage: Architecture, Sequence, ER, State, Medallion, Sankey, Radar, Gantt, Axonometric, and more.
02
Natural-Language Creation
Full lifecycle from draft to refinement handled conversationally—request additions, changes, or rewiring in plain words.
03
Consistent Visual Styling
Disciplined editorial aesthetic: crisp 4px alignment, 1px hairlines, no drop shadows, and 1 focal accent color.
04
Brand Customisation
60-second onboarding pulls colors and typography from any website URL, verifying WCAG AA contrast automatically.
05
Import & Redesign
Ingests raw .drawio, Mermaid, and Excalidraw files, completely redrawing them into branded editorial diagrams.
06
Self-Contained Output
Single portable HTML files with inline SVG; zero external runtime dependencies, node packages, or rendering servers.
Important Architectural Note: Diagram Design does not train or host an AI model. It is an agent skill that equips general-purpose LLMs with visual taste, spatial constraints, and architectural templates.

# Diagram Design: Presentation & 3D Axonometric Architecture

This repository contains the complete academic project presentation, interactive deck, and 3D axonometric architectural engine showcasing the open-source project **Diagram Design** by Cathryn Lavery ([cathrynlavery/diagram-design](https://github.com/cathrynlavery/diagram-design)).

---

## 📦 What's Inside

### 1. Presentation Deck (5 Strict Slides)
Created according to strict editorial guidelines and visual hierarchy rules:
* **Formats:** 
  * PowerPoint Presentation: [`diagram_design_presentation.pptx`](diagram_design_presentation.pptx)
  * Portable Document Format: [`diagram_design_presentation.pdf`](diagram_design_presentation.pdf)
  * Web / Browser Viewer: [`index.html`](index.html)
* **Slides Overview:**
  1. **About the Project**: Overview, purpose, author (Cathryn Lavery), core workflow (`Natural-Language Prompt → AI Agent + Diagram Design → Styled Diagram`).
  2. **How It Works**: 4-stage horizontal process pipeline, key features, and import capabilities (Mermaid, draw.io, Excalidraw).
  3. **Advantages**: 6 structured cards covering speed, visual consistency, natural-language interface, diverse types, portable HTML/SVG, and multi-agent compatibility.
  4. **Application Areas**: Hub-and-spoke layout connecting 6 domains (Software Architecture, Education, Data Engineering, Business Analysis, Project Management, Technical Documentation).
  5. **Future Scope & Conclusion**: Clear distinction between present capabilities and proposed future roadmaps (GUI drag-and-drop, real-time collaboration, auto-validation).

### 2. The 3D Mastercraft Demo: "The Aether Engine"
A monolithic floating computational citadel generated in mathematically pure 3D axonometry:
* **Interactive Web Blueprint**: [`aether_engine.html`](aether_engine.html)
* **High-Resolution PNG Render**: [`aether_engine.png`](aether_engine.png)
* **Generation Script**: [`build_masterpiece_aether.py`](build_masterpiece_aether.py)
* **Technical Highlights:**
  * Strict isometric coordinate projection: $\text{iso}(x, y, z) = [x - y, (x + y)/2 - z]$.
  * Dual-tone shading and silhouette stroke layering (`solid()` + `finish()` engine).
  * Inverted 5-tier stalactite keel descending to $z = -140$.
  * Stepped central plinth, glowing Aether Core reactor (#f08a59), and Chrono-Spire antenna ($z = +282$).
  * Elliptical orbital halos and tethered satellite relay outposts.

Project Overview & Purpose Open Source
Diagram Design is an open-source Agent Skill developed by designer and entrepreneur Cathryn Lavery. It empowers AI coding agents to generate publication-grade technical diagrams as single, self-contained HTML files with inline SVG—free of bloated libraries, heavy renderers, or external dependencies.
The Traditional Diagramming Problem Problem Space
  • Manual Canvas Dragging: Tools like Figma and draw.io require tedious manual alignment, box nudging, and color matching that disrupts developer focus.
  • Generic Automated Tools: Standard text-to-diagram generators (e.g., default Mermaid or PlantUML) often produce visually unrefined layouts with excessive shadows, rigid auto-spacing, and non-branded themes.
Key Architectural Distinction: Diagram Design is not a standalone desktop graphical editor or an independent AI model. It is an agent skill—a structured knowledge framework that teaches host AI coding agents (Claude Code, Cursor, Codex) how to design with disciplined editorial taste.
